# Hi, I'm Frank 👋

Full-stack engineer in Prague, with a frontend core. I've been building software professionally since 2016: **TypeScript, React / Next.js, Vue 3, Node.js and PHP**, with some Python, .NET and Rust along the way.

Most of my career has been at startups and on my own products. At Outfindo I owned the frontend through a full pivot from a B2C aggregator to a B2B embeddable platform, and I co-founded Polyglot, a node-based visual programming tool, where I did the product design and the frontend. My latest engagement was on a national-scale Czech government platform.

I care more about the problem than the framework. I pick the stack that fits, and I use AI for much of the implementation so my time goes into design, architecture and review.

### What I'm good at

- **Owning things end to end.** From product concept and Figma design system to frontend architecture and API integration. On the government platform I independently built and owned an internal admin application inside a 5-person team, and the engagement was extended twice.
- **Config-driven UIs.** I designed a framework that turns a JSON config into a working admin app: routing, pages, forms, tables, modals, plus an action layer and parsers that map OpenAPI schemas to typed models. It got far enough that AI could generate new screens straight from a wireframe.
- **Clean, typed architecture** that a team can keep maintaining, on the frontend and at the API boundary.
- **AI-assisted development.** I build with Claude Code and keep an `AI-LOG.md` in each repo: what the AI did, what I changed, and why.
